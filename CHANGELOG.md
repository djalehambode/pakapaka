📜 CHANGELOG

💡 Bonnes pratiques :
- Utilise un format de journal de modifications clair et structuré.
- Chaque entrée doit être concise mais informative.
- Regroupe les changements par date pour une meilleure lisibilité.
- Utilise des emojis ou des tags pour identifier rapidement le type de changement:
    - 🚀 Added / New
    - 🐛 Fixed / Bugfix
    - ⚙️ Improved / Updated
    - 🧹 Refactored / Cleanup
    - 🗑️ Removed / Deprecated
- Évite les détails techniques trop complexes, concentre-toi sur l'impact utilisateur.
- Mets à jour le changelog régulièrement, idéalement après chaque série de commits significatifs.
- Assure-toi que le changelog est accessible et visible pour tous les contributeurs.



📅 Exemples de format :

🗓️ 2025-10-20
🚀 Added: initial setup for trading bot
✅ Added: basic trading loop with async handling
⚙️ Improved: strategy selection logic
🧹 Refactored: structure of /core/ and /strategies/
🐛 Fixed: incorrect ATR calculation in indicators.py

🗓️ 2025-10-10
🚀 Added: first implementation of performance tracking
🧩 Added: config system for dynamic asset filtering
📁 Moved: logs to /logs/trades/
